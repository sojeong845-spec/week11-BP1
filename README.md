# Morrow Coffee House

세종특별자치시 나성동에 있는 Morrow Coffee House를 소개하는 반응형 홈페이지입니다. 메뉴와 카페 정보를 확인하고, 메뉴를 장바구니에 담아 데모 결제 과정을 체험할 수 있습니다.

## 주요 기능

- 라이트 모드와 다크 모드 전환
- 음료와 디저트 메뉴 필터
- 메뉴별 실제 사진, 가격 및 장바구니 수량 표시
- 장바구니 메뉴와 총액을 확인하는 결제창
- 카드, 간편 결제, 매장 결제 방식 선택
- 모바일 화면에 맞춘 반응형 레이아웃

현재 메뉴는 Morrow 시그니처 라떼, 딸기 우유, 아메리카노, 레몬에이드, 말차 구름 라떼, 초코 생크림 케이크(25,000원), 딸기 생크림 케이크(25,000원), 초코칩 쿠키, 버터 크루아상입니다.

> 결제 기능은 화면 시연용입니다. 실제 결제 또는 청구는 처리되지 않습니다.

## 실행 방법

별도의 설치나 빌드 과정은 필요하지 않습니다. `index.html` 파일을 브라우저에서 열면 됩니다.

## 기술 및 이미지

- HTML, CSS, JavaScript를 `index.html` 한 파일에 포함
- 레몬에이드와 딸기 생크림 케이크 사진은 `assets/`에 포함되어 있습니다. 나머지 메뉴 사진은 Unsplash 및 Pexels 외부 이미지 URL을 사용하므로 인터넷 연결이 필요합니다.
